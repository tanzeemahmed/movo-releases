# movo-releases

Downloads for **Movo** — fast Android to Mac file transfer over USB.

Grab the latest build from the [Releases](https://github.com/tanzeemahmed/movo-releases/releases) page.

Movo pulls photos, video and folders off an Android phone onto a Mac using ADB
rather than MTP, so it is faster and works on phones where Android File
Transfer fails outright.

Requires macOS 14 or later and a USB cable that carries data.
